# Retrospective — STUDIO-3 (wire the real citrate-agent-core)

## What Went Well

**1. The seam pattern scaled.** `policy` and `audit_verify` share one shape: a default
hand-rolled mirror, a `core-live` re-export of the real bridge, and a parity test that
must pass under *both*. Built once for SoD/quorum, it dropped straight onto audit
verification and the quorum decision. It's the reusable mechanism for migrating a heavy
real dependency one surface at a time without destabilizing a shipping app.

**2. The heavy dep was de-risked before it was committed to.** I confirmed the policy
APIs were public and the SSH-sourced `citrate-wallet-core` rev was cached *before* adding
the dependency — so the first `core-live` build resolved offline and just worked, instead
of discovering an SSH wall mid-integration.

**3. The audit wiring is genuinely real, not decorative.** Under `core-live` the scrubber
builds a real `AuditChain` over an in-memory `AuditSink`, "Simulate tamper" corrupts a
real record so the hash chain actually breaks, and the verdict is the runtime's own error
string verbatim — `audit: previous_hash break at sequence 6: chain tampered`. The parity
test is robust to the `audit:` prefix difference, so the two paths stay honest.

**4. Zero UI change.** Every wiring went in behind the seam; no `.slint` file learned
about the core. STUDIO-1's "front end is only a viewport" design paid off exactly as
predicted — this is the concrete evidence that wiring the real core is a swap.

## What Didn't Go Well

**1. The original 8-step plan over-promised what "wire the real core" meant.** I planned
the async `ApprovalQueue`, `DoctorReport`, and `CapsuleDispatch` as STUDIO-3 steps. During
execution I recognized those are *execution / live-deployment inspection* — they need a
real runtime environment (audit files, capsules, a chain, signing keys) the studio demo
doesn't have. The honest move was to refine the scope mid-sprint to "the real core owns
every **pure policy + verification** decision" and push the execution surfaces to
STUDIO-6/5. **Lesson**: when planning a "wire the real X" sprint, separate *pure
decisions* (wireable in-memory, now) from *execution against an environment* (later) up
front — don't lump them, or you either over-scope the sprint or fake a thin wiring.

**2. The parity tests prove agreement on the cases exercised, not total correctness.**
They confirm the modeled default mirrors the real core for the demo's inputs; they don't
exhaustively cover every Role/tier combination. The real core is authoritative; the
modeled default is a convenience the tests keep honest only where they look. Acceptable —
the default is a fast-build stand-in, not the source of truth — but worth stating so the
audit doesn't over-read "parity."

**3. `core-live` carries agent-core's 3 own warnings.** They're the runtime's
`insecure-dev-hitl` cfg, not ours, and the feature is off by default — but anyone enabling
`core-live` sees them. Cosmetic, flagged here so it isn't mistaken for studio debt.

## Honest Assessment of Where We Are

**Strong:**
- Every pure policy/verification decision the UI renders is real-core-backed under
  `core-live`, parity-tested, with zero UI change.
- The seam pattern is a proven, reusable migration tool for the remaining surfaces.

**Needs work:**
- This wires the **policy spine**, not a **running agent**. The majority of a live agent —
  real approvals over real signatures, real capsule execution, real chain anchoring, the
  real doctor against a live environment — is deferred (correctly) to STUDIO-5/6. STUDIO-3
  proves the core *decides*; it does not yet make the core *run*.

## The Partnership Dynamic This Sprint

Larry set a governance bar — a method state-check, a test backfill, and a "interface only
at gate closings" cadence — then let me run autonomously to the gate. The most consequential
call was mine: refining the scope to defer the execution surfaces rather than fake them.
The Agentile discipline of *recording deviations* made that comfortable to do honestly in
the open (in the sprint + this retro) instead of quietly shipping a thin wiring labelled
"done." That's the method working as intended: it made the honest choice the easy one.
