# Retrospective — STUDIO-10 (canvas drives real CapsuleDispatch)

## The Numbers

| Metric | Value |
|---|---|
| Real dispatch trigger | every clip that finishes a tick → a real wasmtime execution (core-live) |
| Output card | modeled scenario `ToolResult` + a "⚡ wasmtime" provenance badge with the real return |
| New tests | `canvas_run_dispatches_real_capsules` (core-live) — 40 core-live / 35 default |
| Builds | both green, zero warnings |
| COMPLETION_STATUS | the canvas live-run flips ⏳ → ✅ |

## What Went Well

**1. The seam from STUDIO-6 made it a wiring job.** `LiveDispatch` already existed and was
tested; STUDIO-10 just had to call it at the right moment — clip completion — and route the
result to the card. The hard part (real wasmtime execution) was done two sprints ago; this
was plumbing.

**2. Honest about the scenario/fleet mismatch.** The demo's `recon.*` clips have no matching
capsule (those land with the upstream packer). Rather than fake a recon result or pretend
the modeled output is real, the run dispatches the real `hello` smoke capsule and the card
shows the modeled scenario result *plus* a clearly-labelled `wasmtime · hello(...)` badge.
The screenshot proves real execution without claiming the recon output is real.

**3. `apply_seed` got more honest too.** It used to hardcode `playhead = 56; status =
"done"`. Now it drives the *real* state machine (tick + dispatch) to the target state, so a
seeded "done" run carries real outputs. The seeds stopped lying.

## What Didn't Go Well

**1. `hello` for every clip is a thin kind of real.** It's genuinely a real wasmtime
execution per clip — but it's the same capsule each time, because the scenario's capsules
don't exist yet. "The canvas drives real dispatch" is true; "the canvas runs the recon
pipeline for real" is not, and the badge is careful to only claim the former.

**2. Dispatch is synchronous on the tick.** `hello` is instant, so calling `call_raw` inline
in the playback tick is fine. A heavier capsule would block the tick; a real pipeline would
need the dispatch off-thread with the playhead gated on completion. That's the shape for
when real capsules exist — noted, not built.

## Honest Assessment

**Strong:** the canvas now genuinely drives real capsule execution under `core-live`, with
real `ToolResult`s surfaced and honestly labelled. The last non-infra functional gap is
closed.

**Needs work:** real *scenario* capsules (upstream packer), off-thread dispatch for heavy
capsules, and chain anchoring (a funded key) — all named in `COMPLETION_STATUS.md`.

## The Partnership Dynamic

Larry named this as the one remaining functional piece that wasn't infra-gated, and it was.
The judgment call — dispatch a real-but-generic capsule and label it precisely, rather than
either fake the recon output or wait for the packer — is the same honesty line the whole
project runs on: make it as real as the environment allows, and say exactly how real that
is.
